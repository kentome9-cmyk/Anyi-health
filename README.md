# 安姨产后健康管理系统

一款专为产后康复门店打造的智能化健康管理平台，集客户档案管理、AI 健康分析、智能内容创作于一体，帮助门店提升服务效率与客户体验。

---

## 核心特色

### 🤖 AI 驱动的健康分析
系统内置 AI 分析引擎，门店只需上传客户的产后健康报告，AI 即可自动解读报告内容，识别健康风险点，并生成个性化的调理方案建议。无需专业知识背景，也能为客户提供专业的健康指导。

### 👥 智能化客户档案管理
每位客户拥有完整的数字化健康档案，涵盖基本信息、产后天数、分娩方式、过敏史、历次到店身体记录、调理方案与执行进度。档案随服务过程自动累积，形成客户全周期的健康轨迹。

### 🎬 一键生成短视频内容
针对门店的线上营销需求，系统提供 AI 短视频创作工具。门店可设定创作者人设与风格，AI 自动生成选题、文案和分镜脚本，大幅降低内容创作门槛，帮助门店持续输出专业的产后健康知识短视频。

- **创作者人设设定**：定义内容赛道、人设风格、目标受众、视频调性、时长等
- **智能选题生成**：基于人设一键生成多个短视频选题
- **文案/脚本生成**：针对选题生成短视频文案或完整分镜脚本
- **原创与改写模式**：支持从零开始创作或基于原文改写
- **脚本历史记录**：自动保存所有生成的脚本，方便回溯复用

### 📚 灵活的知识库支持
后台支持通过 Excel 批量导入产后健康知识条目，内容涵盖调理项目、症状表现、搭配方案等。AI 在分析客户报告和回答问答时，会自动检索知识库内容，确保输出专业、准确。

- **Excel 批量导入**：支持项目名称、表现、搭配效果、症状、搭配项目、搭配原因、调理规划、效果预估等字段
- **可视化管理**：后台支持增删改查，一键清空重建
- **AI 问答检索**：基于知识库的智能问答系统，可检索相关知识后回答

### 🔐 双端权限管理
系统区分门店端与后台管理端。门店端聚焦日常服务场景，界面简洁高效；后台管理端提供数据统计、知识库维护、AI 参数配置等高级功能，满足不同角色的使用需求。

#### 门店端功能
- 客户管理（档案录入、到店记录、调理方案）
- 报告提交与 AI 健康分析
- 方案预览与调整
- AI 问答助手
- 短视频内容创作

#### 后台管理端功能
- 门店管理与门店账号创建
- 客户档案全局查看
- 知识库管理与 Excel 导入
- 提示词模板管理（支持多类型，含变量占位符）
- AI 参数配置（支持双 API：答复 API + 向量 API）
- AI 内容生成记录查看
- AI 问答记录查看
- 到店记录全量数据
- 数据统计总览

### 🔒 数据安全与隐私保护
采用 bcryptjs 密码加密与基于 Cookie 的会话管理机制，客户敏感信息存储于 PostgreSQL 数据库，确保数据安全可靠。

## 快速上手

### 1. 环境准备

确保本地已安装：
- Node.js 18+
- PostgreSQL 12+ 数据库

### 2. 安装与配置

```bash
# 克隆项目后进入目录
npm install

# 复制环境变量模板
cp .env.example .env
```

编辑 `.env` 文件，配置数据库连接：
```env
DATABASE_URL="postgresql://用户名:密码@localhost:5432/anyi_health"
```

### 3. 初始化数据库

```bash
# 生成 Prisma 客户端
npm run db:generate

# 推送数据库表结构
npm run db:push

# 填充初始数据（含默认管理员账号）
npm run db:seed
```

### 4. 启动项目

```bash
# 开发模式
npm run dev
```

访问 http://localhost:3000

## 使用指南

### 后台管理员首次登录

1. 访问 `/login/admin`
2. 使用 seed 数据创建的默认管理员账号登录
3. 进入后台后，建议先完成以下配置：
   - **AI 设置**：配置 AI 接口的 API Key、Agent ID、Base URL、模型 ID、向量 API 等参数，并支持一键测试连接
   - **提示词模板**：预置或自定义各类提示词（方案搭配、选题策划、脚本生成、问答等），支持 `{变量名}` 占位符
   - **知识库**：通过 Excel 批量导入产后健康知识条目
   - **门店管理**：添加门店信息并创建门店登录账号

### 门店日常使用流程

1. **登录门店端**：访问 `/login`，使用管理员分配的门店账号（手机号）登录
2. **添加客户**：在客户管理页面录入客户基本信息与产后情况（姓名、手机、产后天数、分娩方式、身高体重、过敏史、胎次等）
3. **提交健康报告**：上传客户的检查报告，支持文字描述与图片上传
4. **AI 健康分析**：系统自动结合客户档案 + 报告 + 知识库 + 提示词，生成结构化调理建议
5. **制定调理方案**：基于 AI 建议，为客户制定个性化调理方案（含核心项目、辅助项目、到店次数等），支持多版本管理
6. **记录到店情况**：每次服务后记录客户的身体数据与调理进度
7. **AI 问答**（可选）：使用 AI 问答助手检索知识库，快速获取专业建议
8. **内容创作**（可选）：
   - 先在"创作者人设"中配置门店的短视频风格定位
   - 使用"选题生成"快速获取多个选题
   - 基于选题"生成脚本"输出完整分镜文案
   - 或使用"改写模式"基于原文重新组织

### 数据库可视化查看

```bash
npx prisma studio --port 5000
```

访问 http://localhost:5000 即可在浏览器中查看和编辑数据库内容。

## 注意事项

- 首次使用前务必执行 `npm run db:seed` 创建默认管理员账号
- AI 分析功能需要先在后台配置有效的 API 参数并测试连接成功
- 短视频创作功能需要先配置"创作者人设"，AI 才能生成符合门店风格的内容
- `.env` 文件包含敏感信息，请勿提交到版本控制（已在 `.gitignore` 中屏蔽）
- 建议使用 PostgreSQL 12 及以上版本
- 提示词模板中使用 `{变量名}` 格式定义占位符，系统会在调用时自动替换为实际数据
