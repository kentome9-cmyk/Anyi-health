# 演示数据 CSV 导入说明

系统只需要维护 4 张 CSV 表。后台页面支持单张表导入，也支持一次选择多张表后统一导入。

每次导入都会先保存本次上传的 CSV，然后用当前目录里的 4 张 CSV 重新生成演示批次。这样可以保证门店、客户、服务记录、短视频文案之间的关联关系始终一致。

## 使用方式

- 后台页面：真实 admin 登录后进入 `系统管理 -> 演示数据导入`
- 单张导入：在某张表卡片里选择 CSV 后，点击 `导入此表`
- 多张导入：选择一张或多张 CSV 后，点击页面底部 `导入全部已选择表`
- 命令行：在 `nextjs-blog` 目录运行 `npm run demo:seed`
- 清理演示数据：在 `nextjs-blog` 目录运行 `npm run demo:reset`

后台导入页面可以填写 demo 首页的模拟看板数据，包括顶部总览、右侧模块数量和 `7 日数据趋势` 的 7 天合计次数：

- 登录次数
- 操作次数
- AI 分析次数
- 聊天消息

demo admin 首页会优先读取这些模拟看板配置，不再依赖真实明细数量。真实 admin 首页仍然从真实数据库统计。

CSV 明细只需要少量空数据，用来支撑列表和详情页能打开即可。

## 文件位置

正式导入文件：

- `stores.csv`
- `customers.csv`
- `service-records.csv`
- `video-scripts.csv`

参考模板：

- `stores-template.csv`
- `customers-template.csv`
- `service-records-template.csv`
- `video-scripts-template.csv`

## 关联规则

- `门店编号` 是门店唯一编号，必须在门店表里存在。
- `客户编号` 是客户唯一编号，必须在客户表里存在。
- 客户表通过 `门店编号` 归属门店。
- 服务记录表通过 `客户编号` 归属客户，也会按 `门店编号` 归属门店。
- 短视频文案表通过 `门店编号` 归属门店。

## 门店表 stores.csv

字段：

- `门店编号`：门店编号，例如 `store-001`
- `门店名称`：门店名称
- `门店城市`：城市
- `门店地址`：地址
- `门店电话`：门店电话
- `店长姓名`：店长姓名
- `门店登录手机号`：门店端登录手机号

导入到数据库：

- `StoreUser`
- `Store`

## 客户表 customers.csv

字段：

- `客户编号`：客户编号，例如 `customer-001`
- `门店编号`：所属门店编号
- `客户姓名`：客户姓名
- `客户手机号`：客户手机号
- `客户年龄`：年龄
- `产后天数`：产后天数
- `分娩方式`：可填 `顺产`、`剖腹产` 或 `cesarean`
- `胎次`：胎次
- `过敏史`：过敏史，可空
- `客户备注`：备注，可空
- `身高`：身高
- `体重`：体重

导入到数据库：

- `Customer`

## 服务记录表 service-records.csv

字段：

- `客户编号`：客户编号
- `门店编号`：门店编号
- `客户报告`：客户报告内容，可用简短占位
- `方案标题`：调理方案标题
- `调理类型`：调理类型
- `身体记录`：身体记录备注，可用简短占位
- `AI分析`：AI 分析内容，可用简短占位
- `聊天标题`：聊天会话标题
- `用户消息`：客户聊天消息
- `AI回复`：AI 回复消息

导入到数据库：

- `Report`
- `Plan`
- `BodyRecord`
- `AiAnalysis`
- `MenstrualChatSession`
- `MenstrualChatMessage`

## 短视频文案表 video-scripts.csv

字段：

- `门店编号`：门店编号
- `短视频选题`：短视频选题
- `摘要`：选题摘要
- `切入角度`：切入角度
- `核心观点`：核心观点
- `内容方向`：内容方向
- `脚本正文`：脚本文案正文

导入到数据库：

- `Topic`
- `ScriptRecord`

## 兼容说明

导入脚本仍兼容旧英文表头，例如 `store_key`、`customer_key`、`report_content` 等。以后建议统一使用中文表头，方便人工维护。

后台上传接口会自动识别 UTF-8 和 GBK/ANSI CSV，并统一保存为 UTF-8。如果某个 CSV 曾经被旧接口错误保存成乱码，需要重新上传电脑上的原始 CSV 文件；已经变成乱码的文件无法自动恢复中文内容。
